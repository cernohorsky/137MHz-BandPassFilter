# 137 MHz Band-pass Filter
137 MHz bandpass filter for receiving signal from weather satellites NOAA.<br>
<br>
The trace width is designed for a <b>1mm thick PCB</b>, but it should work on 1.6mm as well. The filter requires no tuning—just solder the components and it's ready to go. <br>

That said, don't expect any miracles. It’s only a second-order filter, I highly recommend using this one:<br>
https://github.com/cernohorsky/2m-70cm_BPF/blob/main/README.md <br>

This filter has much higher selectivity.
